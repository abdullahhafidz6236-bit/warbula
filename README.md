# WARBULA

Buku saku digital Kebudayaan Ngawi. Disusun oleh Bagas Junianto.

Website statis dengan animasi StPageFlip. Sumber bacaan, kredit gambar, dan video tersedia pada daftar pustaka di dalam buku. Hak atas media mengikuti sumber masing-masing. Ilustrasi sampul bersifat konseptual.

Untuk GitHub Pages, gunakan branch main dan direktori root. Berkas PDF sumber dan dokumen kerja disimpan terpisah dari repositori publik.
